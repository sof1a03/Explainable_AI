\begin{abstract}
This report will go over the development of a decision-making artificial intelligence model which is innately explainable. The model achieves this explainability by traversing a goal tree and making decisions based on the user's preference and predefined social norms. Finally, the model creates a natural language explanation for the user to explain the steps they took during the decision-making process. In the end, the natural language explanations were submitted for peer evaluation with a Likert scale form to assess the model performance. Based on the form's results the model's explanations performed decently.

\section{Introduction}
With the increased popularity of Artificial Intelligence, more and more people have integrated it into their daily lives. However, most people blindly trust Artificial Intelligence without knowing how it works or makes decisions. This paper aims to create a model that can go through goal trees, make decisions based on user preferences and social norms, and give a natural language explanation of the decision-making process to help the user understand. The initial step was to create an algorithm that enumerates execution traces from a given goal tree while annotating decisions based on the given social norms. Then, the decision-making is optimized by the user-specified preferences. Together, these algorithms ensure that our model considers both the societal norms and preferences of the user at the same time and integrates them into the decision process. The second step was to create natural language explanations for the decisions that the algorithm provided. This way, users can better understand how the algorithm makes its decision. These steps will be explained in greater detail in their corresponding sections. Finally, a peer evaluation was conducted on a Likert scale questionnaire with questions about the quality of the generated explanations.
Section \ref{sec:algorithm} will explain the algorithm used to provide natural language explanations to the user. Then, Section \ref{subsec:experiments} will describe the conducted experiments, the testing process and its data collection and provide an analysis and discussion of these results. Lastly, Section \ref{sec:conclusion}
 will give an overall conclusion.

\section{Algorithm for Generating Natural Language Explanations} \label{sec:algorithm}

The algorithm uses an execution trace to generate an explanation of actions that the agent performed. It maps the agent's actions and the variables for said actions into human-understandable language. This execution trace can contain information about the factors that affect the action to explain. The natural language algorithm loops over these factors and explains them in order. The factors, as shown in Algorithm~\ref{alg:nl_explanation} are:

\begin{itemize}
    \item \textbf{Goal (D):} The goal of the agent.
    \item \textbf{Beliefs - Valid (C):} The condition under which the action is possible.
    \item \textbf{Beliefs - Failed (F):} The condition under which the action is not possible.
    \item \textbf{Preferences (V):} The agent's priorities for selecting actions.
    \item \textbf{Norms - Obligations (O):} The required actions that the agent must follow.
    \item \textbf{Norms - Prohibitions (P):} The prevented actions that the agent must avoid.
\end{itemize}




The algorithm initially describes the goal of the agent and the action taken to achieve this goal. This is achieved by using factors \textit{D}, the agent goal, and \textit{C}, the agent beliefs under which achieving the goal is possible, as shown in the Algorithm~\ref{alg:nl_explanation}. Then, the algorithm explains if the pre-conditions for taking the action are satisfied by the agent's beliefs by utilizing the \textit{C} factor and the \textit{P} factor, prohibited actions that the agent must avoid. After this is done, the algorithm explains the preferences and norms that are provided to the agent and how they fit into the decision-making process. This is done via the use of factors \textit{V} for preferences and \textit{P} and \textit{O} for the prohibited and required norms. Later, the actions that could not be taken are explained with their corresponding failed condition using the factor \textit{F}, agent beliefs under which a specific action is impossible. Finally, the goal and the remaining actions necessary to achieve the goal are mentioned in the last sentence.


\begin{algorithm}
\caption{Generate Natural Language Explanation}
\label{alg:nl_explanation}
\Fn{\FMain{Explanation:}}{
    \KwData{sentences, used\_conditions, used\_plans, chosen\_option, ordered\_prefs, final\_summary}

    \ForEach{factor in explanation\_factors}{
        \eIf{factor type == "D"}{
            \If{factor is "getCoffee"} {main\_goal = "get a coffee"}
            \Else{ chosen\_option = readable\_action(factor[1])}
        }{
            \If{factor type == "C"}{
                precondition\_in\_C = readable\_condition(factor[2])
            }
            \If{factor type == "V"}{
                sentences["V"].append("Preferred " + readable\_action(factor[1]) + " over " + readable\_action(factor[4]))
            }
            \If{factor type == "N"}{
                norm\_violations.append(readable\_action(factor[1]))
            }
            \If{factor type == "P"}{
                precondition\_factors.append("Check " + readable\_action(factor[1]) + " before " + readable\_action(factor[2]))
            }
        }
    }

    \If{main\_goal and chosen\_option} {final\_summary.append("Agent wants to " + main\_goal + " and decided to " + chosen\_option)}
    \If{precondition\_in\_C} {final\_summary.append(precondition\_in\_C)}

    \KwRet{final\_summary}
}
\end{algorithm}

\subsection{Experimentation Setup} \label{subsec:Experimentation}

To evaluate the algorithm presented in Section \ref{sec:algorithm}, a user survey was conducted using FeedbackFruits\footnote{https://feedbackfruits.com}. The survey was generated by the professor and the participants were randomly allocated students from the Explainable AI course at Utrecht University.

Participants were asked to evaluate $5$ different natural language explanations that were generated using the previously described algorithm and a predefined input. For each explanation, participants were asked to evaluate 6 questions (seen in Table \ref{tab:questions}) on a 5-point Likert scale, ranging from 1 (strongly disagree) to 5 (strongly agree). The users were provided both a description of a scenario (following a pre-defined template) and the corresponding explanations.

Each of the questions provided is used to evaluate different criteria for human explanations, which can be seen in Table \ref{tab:questions}.

\subsection{Discussion} \label{subsec:discussion}
As mentioned in previous sections, the decision-making model uses natural language to generate explanations for its decisions. These explanations were evaluated by peer feedback in a Likert scale form. Firstly, one of the key observations from the user feedback is that the generated natural language explanation could be improved in terms of fluency and narrative coherence. The feedback shows that, while the model was informative, the information was fragmented too much, which affected the flow and clarity of the explanation, making it hard for users to understand and piece information together. The feedback also pointed out that the structure of the given explanation and its reasoning made it hard to comprehend how the model came up with its decisions. Another common problem was that the feedback suggests that repeating norms and preferences is redundant. Finally, some of the feedback suggested that the tone of the explanation was too technical, which made it hard to follow. The suggestion was to implement a more realistic and relatable narrative. However, a concern is that this might induce unnecessary text and overcrowd or complicate the explanations even more. Overall, the explanations were found satisfactory by the users and helped their understanding of the process, as seen in both the commentary and Likert scale data. As seen by these remarks and comments, the natural explanations could be improved to achieve a more fluent, consistent, and human-like explanation. In the future, the mentioned problems could be improved on to achieve a better structured and more natural-sounding explanation. Furthermore, more feedback could be received from a more diverse crowd to see how the explanation appeals to different groups of people.

\section{Conclusion} \label{sec:conclusion}

To conclude, this study focuses on a decision-making model and its explainability using natural language explanations. This is an essential method for achieving more transparent and understandable AI models. Although the presented model can traverse the goal tree and come up with a natural language explanation and was found to be satisfactory, the peer feedback conveyed some areas where the model could be improved such as clarity and structure of explanations. This suggests that the explanations should be given in a clearer, more natural and structured manner to help the user understand and provide them with a better user experience. Future work should focus on enhancing these kinds of problems and implementing these explanations to not only decision-specific models but for a variety of AI models. Additionally, gathering more feedback from a more diverse group could reveal more about what to improve in the explanations to make them more accessible and informative. With these kinds of improvements, the model should be able to connect complex algorithmic decision-making and user-friendly, transparent communication.
