\begin{abstract}
This study applies explainable AI techniques to detect pleural effusion in chest X-rays using a DenseNet169 model. Saliency Maps highlight image regions relevant to predictions, while Example-Based Explanations retrieve similar cases for comparison. Explanation quality is assessed using Quantus for Saliency Maps and Normalized Discounted Cumulative Gain (nDCG) for case rankings. This work evaluates which method offers the most useful insights, supporting more transparent and trustworthy AI-assisted diagnosis.
\end{abstract}

\section{Introduction}\label{sec:introduction}
Machine learning is increasingly used to solve complex problems across domains. In healthcare, particularly radiology imaging, AI supports diagnostic and treatment decisions \cite{e2024evaluating}. However, many models act as black boxes with limited insight into how they generate outputs \cite{ahmed2022explainable}, making explainable AI essential to improve transparency and trust.

X-ray analysis is one of the main applications of AI in medicine, especially for detecting bone and lung diseases \cite{miro2022evaluating}. Chest radiography (CXR) systems became even more important during the COVID-19 pandemic, increasing awareness of the need for accurate and explainable tools.

This paper presents a machine learning model for predicting pleural effusion from CXR images. It evaluates two explanation methods: Saliency maps and Cosine Similarity. Their quality is assessed using Quantus \cite{hedstrom2023quantus} and (-----).

\section{Methods \& Materials}\label{sec:methods-materials}
\subsection*{Dataset and Preprocessing}

The dataset used for this study was a downsized version of the CheXpert dataset \cite{ashery_chexpert}, which contains both frontal and lateral chest X-rays. Among the available pathology labels, particular attention was given to the \emph{Pleural Effusion} label, which served as the target for classification.

The dataset was filtered to include only frontal chest X-ray images for consistency. All images were resized to \(224 \times 224\) pixels and normalized to the \([0, 1]\) range. Images with missing or uncertain \emph{Pleural Effusion} labels were removed to improve reliability. To address class imbalance, class weights were computed based on label frequencies and applied during training. The dataset was split into 80\% training and 20\% validation sets. Since the original X-rays were grayscale, each image was duplicated across three channels to match the input format required by ImageNet-pretrained models.

\subsection*{Model Architecture}\label{subsec:model}

To develop the classification model for detecting \emph{Pleural Effusion}, it was adopted a deep learning approach using \textbf{DenseNet169}, a convolutional neural network (CNN) architecture that belongs to the DenseNet family \cite{huang2017densely}.

% DenseNet, short for \emph{Densely Connected Convolutional Network}, uses a unique connectivity pattern in which each layer receives input from all preceding ones and passes its output to all subsequent. This design improves feature propagation and reduces redundant parameters.

\textbf{DenseNet169}, part of the DenseNet family, consists of 169 layers organized into densely connected blocks separated by transition layers that simplifies spatial dimensions for efficiency. It strikes a balance between model depth and computational cost, making it well-suited for medical imaging, where subtle patterns require deep, feature-rich networks \cite{gfg_densenet}. 

The architecture was adapted from an existing implementation \cite{medium_densenet} and initialized with ImageNet \cite{deng2009imagenet}
 pre-trained weights, which capture general low-level features useful for chest X-rays. During training, lower layers were frozen, and upper layers fine-tuned to detect \emph{Pleural Effusion}.


\subsection*{Saliency Map-based Explanations}\label{subsec:saliency-maps}
One form of visual explanation for deep learning models is saliency map-based explanations.  
This report specifically explores the use of Gradient-weighted Class Activation Mapping (\textbf{Grad-CAM}) which uses gradients in the last convolutional layer of the CNN and global-average-pooling to determine each neuron’s importance to the final prediction \cite{selvaraju2017grad}, and can be used to generate heatmaps highlighting the critical information in the image.  
% Grad-CAM has often been used in medical image analysis with good results, for example for classifying tuberculosis lung zones \cite{devasia2023deep}, identifying Covid-19 in chest X-rays \cite{khan2022covid}, and pneumonia \cite{du2023classification}.  

Additionally, to evaluate the quality of the saliency maps, \textbf{Quantus} \cite{hedstrom2023quantus}, a toolkit for evaluating deep learning explanations, has been used. Specifically, it applies the following metrics: Pixel-Flipping \cite{bach2015pixel} for Faithfulness, Local Lipschitz Estimate \cite{alvarez2018towards} for Robustness, Model Parameter Randomisation test \cite{adebayo2018sanity} for Randomisation, Relevance Mass Accuracy \cite{Arras_2022} for Localisation, and Complexity \cite{bhatt2020evaluating} for Complexity.

\subsection*{Example-based Explanations}\label{subsec:example-based-explanations}
Example-based explanations are performed by extracting image feature embeddings from the last pooling layer and ranking images by \textbf{cosine similarity}, which measures vector orientation and magnitude \cite{han2022similarity}. Rankings are compared to expert-defined rankings using \textbf{NDCG} (Normalized Discounted Cumulative Gain), which evaluates ranking quality by assigning relevance scores (in this experiment in the range $[5.5,1]$), computing discounted gain, and normalizing it based on the ideal expert ranking \cite{jarvelin2002ndcg}. This approach evaluates whether the model groups similar images in a clinically meaningful way.

\subsection*{Saliency Maps}\label{subsec:res:saliency-maps}
The GradCAM explanations generated to gain insights about the models' focus on the test images can be seen in Figure \ref{fig:gradcam}.
The most important region, as identified by the model, is represented in seismic colours: red, white, and blue. The bounding boxes on the explanation boxes circle the important parts of the image, that the explanation should focus on. In all five test images, the explanations highlight parts of the bounding box, but often also highlight irrelevant areas outside of it.

In most cases, the heatmaps focus on the lower lung regions associated with Pleural Effusion, suggesting the model identifies clinically relevant areas. However, some explanations highlight unrelated regions, indicating that the model occasionally relies on uninformative features to classify Pleural Effusion.

\section{Conclusion}\label{sec:conclusion}
The understanding of a deep neural network decision-making process is important to make an explainable system.
In this study, multiple methods are used to check the explainability of the model we created.
Overall results showed promising outcomes, especially having a close ranking compared to a professional.
However, there are some improvements to be made in the future to improve the performance and consistency of the model.
